# AI Media Pipeline 🎬⚡

An open-source workflow automation tool designed for AI video creators, content developers, and media editors.

## Features
- **Prompt Builder**: Automated formatting and expansion for AI video generators (Veo, Kling, ComfyUI).
- **Batch Processing**: Streamlines multi-platform output for YouTube Shorts and vertical video formats.
- **Workflow Automation**: Python-based scripts to manage audio synthesis, subtitle alignment, and visual assets.

## Tech Stack
- Python 3.10+
- OpenAI API / Codex Integration
- FFmpeg for media handling

## Quick Start
```bash
git clone https://github.com/Felix-5206/ai-media-pipeline.git
cd ai-media-pipeline
pip install -r requirements.txt
python main.py
